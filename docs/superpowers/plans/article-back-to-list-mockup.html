Metro 打包为什么在 Release 才炸

2 天前· 开发 / react-native, metro· 320 阅读

Xcode 归档时 expo export:embed 走的是裸 node，不是 pnpm shim，所以 NODE_PATH 里根本没有 workspace 的软链。

这件事只在 Release 归档时炸，Debug 一路绿灯，因为 Debug 用的是 Metro dev server，依赖解析完全走另一条路径。

把 babel 和 metro 的间接依赖提成直接依赖，问题就消失了。但这不是根因，根因是 Xcode 的 Bundle React Native code 阶段没有继承 shell 的 PATH。

验证方式很朴素：在 build phase 里 echo 一遍 which node，看它指到哪。

结论是，凡是只在归档时炸的依赖问题，先怀疑执行环境而不是代码。
