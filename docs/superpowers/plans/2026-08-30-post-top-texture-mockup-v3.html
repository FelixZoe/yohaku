Post 天头纹理 · v3

四种背景纹理，全部由数学生成：零随机 seed 位移、零噪点层、无纸质感（不用毛边 / 帘纹 / grain）。每一种都是连续周期场，所以 header 玻璃条 backdrop-blur(16px) 压上去糊出来的是规则的柔和而不是脏色。左边缘 Presence 轨也画了，纹理全部避开左侧 14px。accent 在每种里只作为「一个套色版」出现一小块。

A

网点 · Halftone

印刷网屏

最纯粹的印刷语言：等距点阵，点径自上而下 2.1 → 0.55px 递减到消失。渐变不靠 alpha 斜坡，所以不会有色阶断层，也就完全不需要 grain 去 dither——这正是现在那层噪点存在的唯一理由。accent 是一块偏置的套色网点区，位置由 seed 决定。

B

排线 · Hatch

铜版 / 制图

45° 等距细线，间距 4 → 16px 递减密度做出明暗过渡，铜版画和工程制图的排线法。比网点更"手绘"一点、更有方向性。accent 是一块反向 -45° 的交叉排线（cross-hatch），两版叠加处自然变深，套色关系天然成立。

C

等高线 · Contour

地形 / 制图

一组正弦等高线，振幅与相位由文章 seed 决定——形状因此"每篇不同"却是完全可复算的，不是 feTurbulence 那种不可控的随机。线是几何的，不带任何材质暗示。其中一条压成 accent，是这一页的"水位线"，位置可以绑阅读进度。

D

干涉 · Moiré

网屏叠印

两组几乎同频的竖线（91° / 89°，间距 5px）叠加产生的拍频，再加一版 5.4px 的 accent 线。视觉上是缓慢起伏的明暗带，但没有任何一像素是随机的——摩尔纹本身就是印刷套准偏差的产物。风险：细线在非整数缩放 / 低 DPR 屏上会闪，实现时要靠 SVG 或整数像素兜底。
