取舍要点：
  • 发现性：甲 / 乙 / 丙 三者皆于 TOC 直见状，胜现况之埋于弹板
  • 语义：甲（segmented）字面直示 — 即「宋」即「楷」；乙之 toggle 需另附文；丙之 chip 隐含切之 affordance
  • 扩展性：甲可加第三段（如「黑」「圆」）；乙限于二态；丙循环 N>2 时点错代价大
  • 视觉占位：甲约 80px 宽（二段），乙约 56px（标 + 开关），丙约 40px（chip）；TOC 侧栏宽 256px 内皆容
  • 对齐既有 idiom：dev/lexical demo 已用 Segmented，复用之
