Waterdrop ripple · Canvas2D

与 AjisaiBackground 同一族：Canvas2D 内绘水珠 ctx.ellipse，重力加速坠落（t^2.2，自帧外起以蓄速）。 触水非淡化而是融化——alpha 全程为 1，scaleY 缓塌至 0、scaleX 同时外摊（pancake），bottom 始终锚于水线，几何上"压平入水"。 涟漪用 ctx.ellipse(x,y,r,r*0.32,...) 作俯视椭圆，两道错峰。 所有实例共一 RAF；色取 currentColor，dark 自适。

实现要点
· 结构：单 <canvas>，css 尺寸定大小，JS 内部按 DPR 放大画布。无嵌套 DOM。
· drop：ctx.ellipse 通绘。下落占 cycle 的 0.00–0.15，用 t^2.2 加速；自 y = -4·r（帧外）起，入帧仍只见高速末段。触水后 0.15–0.24 保 alpha=1，scaleY=(1-p)^2.2 → 0 + scaleX → 1.68，bottom 锚水线，即"压平入水"之形，无半透淡出。
· ring：ctx.ellipse(x, y, r, r * 0.32, ...)，aspect 0.32 = 俯视水面。第一道自 0.15 起至 cycle 末，第二道自 0.44 起，半径约 75%、峰值 alpha 约 60%。
· color：JS 读 getComputedStyle(el).color，即继承 CSS color。父容器换色（如 .btn 用 accent）即跟随。
· RAF：所有实例共一 ticker（requestAnimationFrame 单循环），活实例列表驱动。off-screen 可入 IntersectionObserver 暂停（此 mockup 暂未加，React 实现时再补）。
· React API：<LoadingMark size="sm|md|lg" cycle?={ms} rings?={1|2}/>。旧 <Loading inline text/> 仅换内部 mark。
