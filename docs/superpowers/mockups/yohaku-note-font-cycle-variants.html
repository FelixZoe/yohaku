循环按钮 — 形态六变

皆采单点循环（点行内任处即换至次字体），所变唯当下态之示法。 二要点：① 当下用何字一目即明 ② 点之为切换之能须暗示。
hover 卡片以见次态。

A

标 + 当下名（以己体渲）

「字形」标存，右侧示当下字体名 — 以己体写，本身即预览。 hover 现 ↻ 之微提示。

入题
现况
Ａ 字形 楷 ↻
  • + 直觉：字本身即所选字体之样
  • − 多一标「字形」似冗
B

仅名 · 弃标签

「字形」标去之，icon 已足表义。仅显当下字体名（以己体）， hover 现「→ 宋」次态提示（以次态字体渲）。

入题
现况
Ａ 楷书 · 霞鹜文楷 → 宋
  • + 最简，无冗字
  • + 名以己体渲 + hover 现次态以次体渲 = 二态皆见
  • − 占行宽较多（含「霞鹜文楷」全名）
C

双字预览 · active 下划线

右侧并列「字字」二样，各以己体；active 者以 accent 下划线、深色； inactive 者灰。点行即切。

入题
现况
Ａ 字形 字 字
  • + 二态皆见，比较直观
  • − 视觉近 segmented（即甲案），仅省 chip 边框
D

Chip 居右 · 以己体

初版之改良：chip 内字以己体渲（非默 sans）。 chip 形已暗示「可点」。

入题
现况
Ａ 字形 楷
  • + chip 形天然示可点
  • − chip 边框 + 行 hover 双重视觉
E

方钮 · 单字

右侧立方钮（28×22），内嵌单字之当下体；hover 现 accent 边。 chip 之方化，更克制。

入题
现况
Ａ 字形 楷
  • + 方钮形似 control，可点意明
  • + hover 边框为 accent，状态语义清
  • − 与 TOC 行内其余无背景之文字差异较显
F

名 + 微 caret

右侧示「楷 ⌄」之样，无 chip 无背景；caret 暗示可换。 最轻量，与 TOC 文本行无视觉冲突。

入题
现况
Ａ 字形 楷 ▾
  • + 最轻，与 TOC 行 weight 一致
  • − caret 通常暗示「展开下拉」，循环切语义略有歧义
选断指引：
  • 要直观 → A 或 B（字本身即字体之样）
  • 要二态俱见 → C（接近 segmented 但更轻）
  • 要 control 之感 → D chip 或 E 方钮
  • 要最轻 → F 名 + caret，但 caret 语义须斟酌
我倾 A：当下名以己体渲是最直观之预览；hover ↻ 之微示足明可循环；标「字形」与其他 TOC accessory（阅读进度）形式齐。
